# PizarrApp

La aplicación permitirá gestionar de forma centralizada tanto la lista de la compra como las tareas del hogar.
Todos los miembros podrán añadir productos, marcar artículos comprados, crear tareas domésticas y consultar el estado general de la vivienda.
